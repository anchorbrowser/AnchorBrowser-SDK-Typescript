# Security Policy

## Reporting Security Issues

Anchorbrowser takes security seriously, and encourages you to report any security
vulnerability promptly so that appropriate action can be taken.

To report a security issue in this SDK, please contact support@anchorbrowser.io.

## Responsible Disclosure

We appreciate the efforts of security researchers and individuals who help us maintain
the security of our SDKs. If you believe you have found a security vulnerability, please
adhere to responsible disclosure practices by allowing us a reasonable amount of time to
investigate and address the issue before making any information public.

## Reporting Non-SDK Related Security Issues

If you encounter security issues that pertain to Anchorbrowser services or products
rather than this SDK, please contact support@anchorbrowser.io.

---

Thank you for helping us keep our SDKs and the systems they interact with secure.
